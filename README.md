# hackaton_mt
# Предиктор изменений в графике наземного транспорта

> **Хакатон Московского транспорта** | Трек: Predictive Transport Analytics  
> Команда: **ustroy_destroers67**

## Описание решения
Интеллектуальная система раннего прогнозирования отклонений в движении наземного пассажирского транспорта. Решение анализирует потоковые телематические данные (NDTP), сопоставляет их с эталонным расписанием и предсказывает вероятность задержки за **10–15 минут до фактического наступления события**. Это позволяет диспетчерам переходить от реактивного управления к проактивному принятию решений.
