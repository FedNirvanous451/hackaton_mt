# Краткий отчёт по ML

## Задача

Прогноз задержки городского транспорта в секундах на первой остановке в окне `(T+10 минут, T+15 минут]`. Основная метрика — MAE, меньше — лучше.

## Данные

- реальные и синтетические обучающие наблюдения;
- официальный размеченный test из 353 реальных наблюдений;
- скрытый validate из 151 реального наблюдения;
- из обучающих таблиц исключены целевые события официального test;
- признаки рассчитываются только по информации, доступной на момент `T`.

## Проверенные модели

| Модель | MAE test, сек. |
|---|---:|
| ExtraTrees | **42.82** |
| CatBoost | 51.34 |
| HistGradientBoosting | 53.72 |
| Ансамбль | 54.88 |
| MLP | 59.06 |
| XGBoost | 77.86 |
| LightGBM | 78.71 |
| ElasticNet | 93.08 |

Результаты дополнительных временных разбиений использовались как диагностика устойчивости. Итоговая модель выбрана по официальному размеченному test, который по регламенту предназначен для локальной проверки и подбора.

## Итоговая модель

ExtraTrees с 400 деревьями, глубиной 15, `min_samples_split=5`, `min_samples_leaf=4` и `max_features=1.0`. Медианное заполнение пропусков включено в общий `Pipeline`.

Повторный запуск `train.py` даёт MAE около 42.72 сек. Готовая модель запускается через FastAPI и возвращает прогноз, горизонт и наблюдаемые паттерны движения.

## Защита от утечки

- `target_delay_s` не входит в признаки;
- `time_fact_begin` не используется при инференсе;
- агрегаты телеметрии ограничены условием `event_time <= T`;
- API отклоняет запросы вне горизонта 10–15 минут.
