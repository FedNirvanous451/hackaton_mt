# Sphinx: документация по коду

Чтобы добавить документацию к готовому решению, скопируйте папку `docs/`
целиком в корень проекта рядом с `backend/` и `ml_core/`. Сайт уже собран:
откройте `docs/index.html`. Для просмотра готовых HTML-страниц устанавливать
Sphinx не нужно.

Исходники страниц находятся в [`source/`](source/). Sphinx импортирует модули
`backend/app/` и `ml_core/` и создаёт страницы с сигнатурами, типами и
docstring функций и классов.

Из корня проекта установите зависимости и соберите HTML:

```powershell
python -m pip install -r backend/requirements.txt -r ml_core/requirements.txt -r docs/requirements.txt
python -m sphinx -b html -W --keep-going -d docs/.doctrees docs/source docs
```

Откройте [`index.html`](index.html) в браузере. Готовый HTML находится прямо
в `docs/` и может раздаваться GitHub Pages из папки `/docs` ветки проекта;
файл `.nojekyll` сохраняет доступ к служебным папкам Sphinx с префиксом `_`.
Для публичной ссылки после загрузки репозитория нужно включить GitHub Pages
в настройках репозитория (источник: ветка проекта, папка `/docs`).

Сборка документации не требует локальный `dataset/` и не загружает файл
обученной модели: Sphinx импортирует определения модулей без запуска
серверов, обучения и обработки данных.
