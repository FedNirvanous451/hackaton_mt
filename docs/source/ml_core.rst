ML-ядро: Python-модули
======================

API прогноза
------------

``api.main`` описывает входные и выходные поля модели, проверяет горизонт
прогноза и выполняет инференс загруженной модели.

.. automodule:: api.main

Признаки и наблюдаемые паттерны
--------------------------------

``features`` содержит список признаков и подготовку таблицы для модели.
``patterns`` возвращает понятные условия движения рядом с прогнозом.

.. automodule:: features

.. automodule:: patterns
