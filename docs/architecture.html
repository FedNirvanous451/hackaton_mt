Устройство системы¶

Система запускается четырьмя сервисами Docker Compose: ml, backend, frontend и emulator. Обязательные для работы панели модули — ML-ядро, backend и frontend. Эмулятор предоставляет один из источников телеметрии.

Исторические CSV ─┐
                  ├─> Backend ──HTTP /predict──> ML-ядро
Эмулятор ──NDTP───┘       │
                          ├─HTTP: расписание, история, метрики
                          └─WebSocket: текущие срезы ──> Панель MapLibre

Backend связывает идентификатор устройства с транспортным средством, сопоставляет телеметрию с расписанием и рассчитывает признаки по сообщениям, полученным не позднее момента прогноза. ML-ядро возвращает задержку в секундах; backend прибавляет её к плановому прибытию и формирует предупреждения.

Исторический режим читает dataset/<split>/traffic.csv последовательными кадрами. API позволяет запросить пройденные точки и весь список плановых остановок для восстановления карты после переподключения. Живой режим принимает NDTP-пакеты по TCP и публикует обновления через WebSocket.

Frontend сохраняет выбранный источник, исторический курсор, фильтры и камеру карты в браузере. При отказе эмулятора он переключается на исторический поток. Текущее серверное состояние хранится в памяти одного процесса; внешнее расписание после перезапуска backend нужно отправить снова.
