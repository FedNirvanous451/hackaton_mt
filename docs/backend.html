Приём и обработка телеметрии¶

NDTP TCP receiver for navigation and optional IRMA door status.

Признаки, хранилище и история¶

backend.app.features строит вход ML по телеметрии. store хранит регистрации, расписание и фактические прибытия; history загружает CSV и воспроизводит события по времени.

Online aggregates required by ml_core’s published /predict contract.

The five-minute windows and GPS rules mirror ml_core/prepare_data.py. The ML service itself remains an independent, unmodified component.
