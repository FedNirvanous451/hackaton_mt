# Карточка модели

- Алгоритм: `ExtraTreesRegressor` в `Pipeline` с медианным заполнением пропусков.
- Цель: `target_delay_s`, задержка прибытия в секундах.
- Горизонт: `(T+10 минут, T+15 минут]`.
- Локальная проверка: MAE 42.72 сек. при воспроизведении `train.py`.
- Параметры: 400 деревьев, глубина 15, `min_samples_split=5`, `min_samples_leaf=4`, `max_features=1.0`.
- Признаки: координаты целевой остановки, горизонт, свежесть телеметрии, скорости за 1/3/5 минут, изменение и разброс скорости, доля остановки, количество валидных сообщений, расстояние, текущее отклонение и время суток.
- Защита от утечки: `target_delay_s` и `time_fact_begin` не входят в признаки; телеметрические агрегаты должны рассчитываться только по сообщениям с `event_time <= T`.
- Ограничение: API принимает уже рассчитанные телеметрические агрегаты; их онлайн-расчёт выполняет backend.
- Объяснение: API возвращает наблюдаемые паттерны движения по прозрачным правилам. Они помогают интерпретировать прогноз, но не доказывают причинно-следственную связь.
